# Roadmap 与待确认项

## v0.1：已完成

- RSS/Atom 与 arXiv 真实采集。
- 规则优先、可解释评分。
- 双轴论文硬门槛。
- SQLite、Dashboard、离线演示、导出与反馈记录。

这个版本的目标是让你先观察：来源是否合适、误报/漏报在哪里、评分拆解是否符合你的判断。它没有把未经验证的复杂模型一次性塞进主流程。

## v0.2：已完成

1. 主库与 DEMO 数据库物理隔离。
2. 来源域名白名单、链接可达性和跳转终点验证。
3. arXiv API ID 与官方摘要 URL 一致性验证。
4. 来源健康历史和 Dashboard 溯源凭据。
5. 默认页面与导出仅使用已验证条目。

## v0.2.1：已完成

1. 论文页默认按北京时间自然日展示。
2. 近 4 日回补与历史论文独立展示，不再冒充今日论文。
3. 每日导出默认排除往日论文。

## v0.3：已完成

1. 新闻范围覆盖整个 AI 领域，不限定自动驾驶或多模态。
2. 主 Feed 只接收模型/工具/数据集发布与可验证的技术成果事件。
3. 媒体和社区来源采用标题锚定，避免长摘要中的历史事件触发误报。
4. Sponsored、付费内容、观点、融资和司法监管动态默认排除。
5. 新闻门槛规则版本化，旧版宽松结果不再进入正式 Feed。

## v0.4：已完成（GitHub Pages 预览）

1. 生成不依赖 FastAPI 服务器的只读静态站点。
2. 支持新闻/论文、精选/全部、论文今日/近 4 日与本地全文搜索。
3. 页面展示逐条来源凭据、最近采集任务与逐来源健康状态。
4. GitHub Actions 每天在云端执行测试、真实采集、静态构建与 Pages 发布。
5. 同步输出机器可读 JSON、Markdown 和 RSS。

## v0.5：当前版本（DeepSeek 语义筛选与邮件）

1. 使用 `deepseek-v4-pro`、Thinking `max` 对全部已验证候选做正式语义筛选。
2. 新闻与论文 Prompt 独立版本化，并保存 Prompt 哈希。
3. 记录逐次 Token、推理 Token、缓存命中和估算费用，设置每日双限额。
4. GitHub Pages 展示用量，同日重复运行恢复已发布的累计用量。
5. 支持 163 SMTP 定时邮件，地址和授权码仅由 GitHub Secrets 注入。

## v0.6：下一轮质量增强

1. 用本地 sentence embedding 改进新闻事件聚类和用户兴趣相似度。
2. 接入 Hugging Face Daily Papers、Semantic Scholar/OpenAlex，补充代码、数据集和社区元数据。
3. 根据 `saved` / `not_relevant` 反馈训练轻量兴趣模型。
4. 建立人工标注样本，展示 Precision@K，而不是凭主观感觉继续调权重。
5. 在现有来源健康记录上增加连续失败次数、每日有效条目数和 AI 密度趋势。

## v0.7

1. 可选的历史归档与公开仓库定时工作流保活策略。
2. 飞书或企业微信推送。
3. 为本项目制作两个薄 Skill：
   - `daily-ai-radar`：读取已经生成的结构化日报并回答新闻问题。
   - `vla4ad-paper-radar`：查询、比较、收藏领域论文。
4. Skill 不直接取代采集核心；数据库和结构化 JSON 始终是事实来源。

## 需要通过预览验证的判断

- AI 新闻每天精选 10–15 条是否合适。
- “影响力”是否需要偏研究、偏工程或偏产业。
- MLLM/VLM 只用于驾驶场景理解的论文是否放在主 Feed。
- 世界模型是否必须包含语言或 Action 才能进入主 Feed。
- 开环评测、闭环评测、代码可用性的相对权重。
- 最终首选推送渠道。
